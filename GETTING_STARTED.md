# 🚀 Быстрый старт WhisperFlow MVP

Инструкция по запуску MVP версии WhisperFlow.

## Предварительные требования

### Системные требования

- **OS**: Windows 10/11 (для Desktop app), Ubuntu 22.04+ (для Backend)
- **Node.js**: 18+
- **pnpm**: 8+
- **Python**: 3.11+
- **OpenAI API Key**: Обязательно!

### Получение OpenAI API Key

1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Создайте API ключ в разделе API Keys
3. Пополните баланс (минимум $5 для тестирования)

## Установка и запуск

### 1. Backend API

```bash
# Перейти в директорию backend
cd backend

# Создать виртуальное окружение (рекомендуется)
python -m venv venv

# Активировать виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Создать .env файл из примера
cp .env.example .env

# ВАЖНО: Отредактировать .env и добавить ваш OPENAI_API_KEY
# Windows:
notepad .env
# Linux/Mac:
nano .env

# Запустить сервер
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend API будет доступен на `http://localhost:8000`

API документация (Swagger): `http://localhost:8000/api/docs`

### 2. Desktop App

**В новом терминале:**

```bash
# Перейти в директорию desktop
cd desktop

# Установить зависимости
pnpm install

# Создать .env файл из примера
cp .env.example .env

# Убедиться, что VITE_API_URL указывает на backend
# По умолчанию: http://localhost:8000

# Запустить приложение в режиме разработки
pnpm dev
```

Desktop приложение откроется автоматически.

## Использование MVP

### Базовый workflow

1. **Запись аудио**
   - Выберите источник: Микрофон / Системный звук / Оба
   - Нажмите "Начать запись"
   - Говорите или воспроизводите аудио
   - Нажмите "Остановить"
   - Файл автоматически отправится на транскрипцию

2. **Загрузка файла**
   - Нажмите "Загрузить файл"
   - Выберите аудио файл (mp3, wav, m4a и др.)
   - Файл автоматически отправится на транскрипцию

3. **Транскрипция**
   - Наблюдайте за прогрессом в реальном времени
   - Ожидайте завершения (обычно 1-2 минуты на 10 минут аудио)
   - Результат отобразится в панели "Транскрипция"

4. **Форматирование** (опционально)
   - После завершения транскрипции выберите формат:
     - Краткое резюме
     - Список пунктов
     - Структурированный текст
     - Деловое письмо
     - Заметки
   - Нажмите "Отформатировать"
   - Результат отобразится в панели "Форматирование"

5. **Экспорт результатов**
   - Используйте кнопки "Копировать" или "Скачать"
   - Результаты сохраняются в базе данных

## Ограничения MVP

- ✅ Основная функциональность работает
- ⚠️ Нет аутентификации (один пользователь)
- ⚠️ Нет истории транскрипций в UI (есть в backend)
- ⚠️ Используется SQLite (не для production)
- ⚠️ Нет Celery (синхронная обработка, может быть медленно)
- ⚠️ Нет Rate Limiting

## Возможные проблемы и решения

### Backend не запускается

```bash
# Проверить версию Python
python --version  # Должна быть 3.11+

# Переустановить зависимости
pip install -r requirements.txt --force-reinstall

# Проверить .env файл
cat .env  # Linux/Mac
type .env  # Windows
```

### Desktop app не подключается к backend

1. Проверить, что backend запущен: `curl http://localhost:8000/health`
2. Проверить `desktop/.env`: `VITE_API_URL=http://localhost:8000`
3. Перезапустить desktop app

### OpenAI API ошибки

**"Invalid API key"**
- Проверьте OPENAI_API_KEY в `backend/.env`
- Убедитесь, что ключ активен на platform.openai.com

**"Insufficient quota"**
- Пополните баланс на platform.openai.com

**"Rate limit exceeded"**
- Подождите несколько секунд и попробуйте снова

### Ошибки записи аудио

**"Permission denied"**
- Разрешите доступ к микрофону в браузере/системе
- В Windows: Settings → Privacy → Microphone

**"System audio not working"**
- Системный звук требует дополнительных разрешений
- Используйте только микрофон для тестирования
